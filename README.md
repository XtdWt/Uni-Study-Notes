# Study Notes

## About
Mathematics study notes written in Typst and compiled to pdf and svg. [Website](https://xtdwt.github.io/Uni-Study-Notes/) using Github static hosting.
<br>
## Setup
Requires [Typst](https://github.com/typst/typst) to do the compiling.
<br>
cli command for compiling pdfs:
<br>
`cd FOLDER_NAME_HERE
typst compile "FOLDER_NAME_HERE.typ" notes.pdf`
<br>
cli command for compiling svgs:
<br>
`cd FOLDER_NAME_HERE
typst compile "FOLDER_NAME_HERE.typ" "svgs/page_{p}.svg"`
