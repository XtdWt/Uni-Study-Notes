# Study Notes

## About
Mathematics study notes written in Typst and compiled to pdf and svg. Website using Github static hosting.
<br>
## Setup
Requires Typst cli
<br>
compiling pdfs:
<br>
`cd FOLDER_NAME_HERE
typst compile TYPST_FILE notes.pdf`
<br>
compiling svgs:
<br>
`cd FOLDER_NAME_HERE
typst compile TYPST_FILE "svgs/page_{p}.svg"`
